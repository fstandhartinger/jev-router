# Provider and model rights

Checked 22 September 2026. This is a conservative launch record, not legal advice.

Jev Router offers only independently hosted open models whose runtime and weights permit this use. The current djev paths use the Apache-2.0 `Davipar/djev-dev` runtime or the open djev-spark structured-read runtime with Apache-2.0 DiffusionGemma weights. Maisa's hosted djev API is not proxied.

Hosted compute pricing is the provider's real per-minute cost plus the disclosed margin. Shared warm routes publish their per-decision price. Provider inventory and prices can change; an instance start records the applicable rate before provisioning.
